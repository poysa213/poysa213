I build full stack web and mobile products, and I connect them to AI systems that hold up in production.

Most of my work is in Python and TypeScript. On the product side that means React and Next.js on the web, React Native on mobile, with NestJS or Django behind them. On the AI side I build agent based systems with LangChain and LangGraph: retrieval, tool calling, and workflows that stay reliable once real users start using them.

Security is part of how I work, not a step at the end. I came from CTFs, and I use the same mindset on the products I ship, from common web issues to newer ones like prompt injection and unsafe tool access.
